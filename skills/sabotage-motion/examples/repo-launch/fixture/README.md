# Snagwick

Snagwick finds every TODO, FIXME and HACK in your code and puts them on one board you can sort.

## Install

```sh
npm install -g snagwick
```

## Features

- Finds every TODO, FIXME and HACK, in any language with comments
- Groups them by file, by tag and by who left them
- Opens a board on localhost you can sort, filter and check off

## Usage

```sh
snagwick scan          # read the project and list what it found
snagwick board         # open the board on http://localhost:4747
```
